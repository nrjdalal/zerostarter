# Fonts

Every font loads through `next/font/local`, which generates the metric-adjusted fallback face that holds CLS near zero. A fontsource CSS import resolves its `url()` into `node_modules` (a 404 in dev) and ships no fallback metrics, so the loader is the only path.

## 1. Fetch the latin variable woff2

```bash
curl -fL -o web/next/src/fonts/<name>-latin-wght-normal.woff2 \
  https://cdn.jsdelivr.net/npm/@fontsource-variable/<name>/files/<name>-latin-wght-normal.woff2
```

A family that ships an italic (its package serves a `wght-italic.css`, as the shipped sans's does) also takes `<name>-latin-wght-italic.woff2` the same way; skip it and every italic synthesizes. No dependency: `-f` turns a wrong name into a non-zero exit instead of an HTML page on disk. Done when curl exits 0 and each file is on disk.

## 2. Declare it

In `web/next/src/lib/fonts.ts`, which the root layout imports, so every font there preloads on every page, or in a route-only module, since preload follows the import graph (the canonical starter's `lib/marketing/fonts.ts`):

```ts
export const <export> = localFont({
  src: "../fonts/<file>", // relative to this module
  variable: "--font-<name>",
  weight: "<min> <max>", // curl -s https://cdn.jsdelivr.net/npm/@fontsource-variable/<name>/index.css | grep font-weight
})
```

Omitted, `weight` leaves the face at 400 and every bold glyph synthesizes. A family with both faces takes `src` as an array of `{ path, style }`, `"normal"` and `"italic"`, as `dmSans` does; an italic-only file sets `style: "italic"`; a serif adds `adjustFontFallback: "Times New Roman"` (the metrics default to Arial); the mono renders synthetic oblique for italics, by choice. A swap also removes the font it replaces (step 6), or every page keeps preloading a face nothing renders. Done when the export carries `variable` and a `weight` matching that CSS.

## 3. Apply it

`.variable` on `<html>` in `app/layout.tsx` exposes the font to the theme. A route-only font takes `.className` on the elements that render it and skips step 4. Done when `rg "<export>\.(variable|className)" web/next/src` hits.

## 4. Wire the role

In `globals.css` `@theme inline`: `--font-<role>: var(--font-<name>), <generic>`. The sans also moves `FONT` in `packages/scripts/src/data-table-metrics.ts` (the table measures header labels from bundled metrics of that woff2, regenerated by `build`, `check-types` and `dev:app`) and `FONT_TO` in `.github/scripts/shadcn-customize.ts` (or the next sync restores the old sans). A face for another role whose line the registry writes (`--font-heading`) is a new override, or the next sync reverts it: add its guarded swap in `.github/scripts/shadcn-customize.ts` and list it under Guards in the `shadcn-sync` skill, through that skill's step 4. Done when `rg -- "--font-<name>|<file>" .github/scripts/shadcn-customize.ts packages/scripts/src/data-table-metrics.ts web/next/src/app/globals.css` hits the role, for the sans in all three files, and for another registry-written role in `globals.css` and `shadcn-customize.ts`, with `rg -- "--font-<role>" .agents/skills/shadcn-sync/SKILL.md` hitting its Guards entry.

## 5. Verify

The route's stylesheet carries a face whose name ends in `Fallback` with `size-adjust` and a hashed `media/*.woff2` src; the rendered DOM carries one `<link rel="preload" as="font">` per file the route loads (dev serves them as hints that React hoists, so read the DOM through the browser rather than the HTML). Done when the preload count matches the route's files, every font request answers 200, and a `PerformanceObserver` on `layout-shift` (`buffered: true`) in the console records nothing on a changed public page.

## 6. Remove a font

Delete each woff2 the `localFont` lists, the `localFont` itself, and the `.variable` or `.className` use, then hand the role on: the sans repoints the role, `FONT` and `FONT_TO` at the replacement; a registry-written role (`--font-heading`) returns to the registry's value, `var(--font-sans)`, and drops its guarded swap and its `shadcn-sync` Guards entry; any other role repoints at its replacement or its generic family. Done when, for each file the font listed (`<file>` is its basename), `find web/next/src/fonts -name '<file>'` prints nothing and `rg -- "--font-<name>|<file>" .github/scripts packages/scripts web/next/src web/next/content .agents/skills/shadcn-sync` is empty; for a registry-written role other than the sans, `rg -- "--font-<role>" .github/scripts/shadcn-customize.ts .agents/skills/shadcn-sync/SKILL.md` is empty too; and `bun run check-types` passes.
