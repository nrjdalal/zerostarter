Cafe ships two variable fonts, self-hosted via `next/font/local`, wired to Tailwind font utilities in `globals.css`.

| Utility     | Token         | Font           |
| ----------- | ------------- | -------------- |
| `font-sans` | `--font-sans` | DM Sans        |
| `font-mono` | `--font-mono` | JetBrains Mono |

`--font-heading` aliases `--font-sans`, and `html` defaults to `font-sans`.

## Samples

## Usage

```tsx
<h1 className="text-3xl font-bold tracking-tight">Heading</h1>
<p className="text-muted-foreground text-sm">Supporting copy.</p>
<code className="font-mono text-sm">apiClient.health.$get()</code>
```
