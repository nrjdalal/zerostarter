title: Colors
description: Semantic color tokens used across Cafe. Defined as CSS variables in globals.css.
---

Colors are defined as semantic CSS variables in `web/next/src/app/globals.css` using `oklch`, with light values on `:root` and dark values on `.dark`. Always use the semantic token, never a raw color.

| ---------------------------------------------------------------------------------------------------------------- | -------------- |
| <span className="inline-block size-5 rounded border align-middle" style={{ background: "var(--background)" }} /> | `--background` |

## Usage

Use the matching Tailwind utility, foreground pairs belong on their background:

```tsx
<div className="bg-primary text-primary-foreground">Primary</div>
<div className="bg-muted text-muted-foreground">Muted</div>
<p className="text-destructive">Something went wrong</p>
```
