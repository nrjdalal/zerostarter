## Overview

ZeroStarter includes full-text search powered by [Orama](https://orama.com) via Fumadocs. The search indexes all documentation and blog content and is accessible via a keyboard shortcut or the sidebar search input.

## How It Works

The search endpoint at `web/next/src/app/api/search/route.ts` uses Fumadocs search server with Orama:

```ts
import { createSearchAPI } from "fumadocs-core/search/server"
import { source } from "@/lib/source"

export const { GET } = createSearchAPI("advanced", {
  indexes: source.getPages().map((page) => ({
    title: page.data.title,
    description: page.data.description,
    url: page.url,
    id: page.url,
    structuredData: page.data.structuredData,
  })),
})
```

The Next.js config rewrites `/api/search` to the internal app URL to avoid CORS issues:

```ts
{ source: "/api/search", destination: `${env.NEXT_PUBLIC_APP_URL}/api/search` }
```

## Usage

### Keyboard Shortcut

Press `Cmd+K` (Mac) or `Ctrl+K` (Windows/Linux) to open the search dialog from any docs page. The sidebar search component at `web/next/src/components/sidebar/docs/search.tsx` displays the platform-appropriate hint.

### Search Dialog

The search dialog is provided by Fumadocs and supports:

- Full-text search across all content
- Heading-level results for navigation within pages
- Keyboard navigation of results
