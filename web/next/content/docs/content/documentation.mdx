## Overview

Documentation is managed using [Fumadocs](https://fumadocs.vercel.app) and stored in `web/next/content/docs/`. Full-text search is powered by [Orama](https://orama.com) via Fumadocs.

## Content Structure

- **Location**: `web/next/content/docs/`
- **Format**: MDX files with frontmatter
- **Configuration**: Defined in `web/next/source.config.ts` and `web/next/content/docs/meta.json`

## Creating Documentation

1. Create a new `.mdx` file under the appropriate folder in `web/next/content/docs/`
2. Add frontmatter with `title` and `description`
3. Write content using MDX syntax
4. Add the filename to the `pages` array in that folder's `meta.json`

## Configuration

Documentation source is configured in `web/next/source.config.ts`:

```ts
export const docs = defineDocs({
  dir: "content/docs",
})
```

Navigation is driven by **a `meta.json` in each folder**. The root `meta.json` lists top-level sections; each folder's `meta.json` lists the pages inside it. The array order is the sidebar order — a page absent from `meta.json` won't appear in the sidebar.

**Root `web/next/content/docs/meta.json`** — section order:

```json
{
  "pages": [
    "index",
    "getting-started",
    "guides",
    "features",
    "operations",
    "content",
    "deployment",
    "resources",
    "about"
  ]
}
```

**Per-folder `meta.json`** — page order inside a section:

```json
// web/next/content/docs/getting-started/meta.json
{
  "title": "Getting Started",
  "pages": ["setup", "architecture", "project-structure", "scripts", "type-safe-api"]
}
```

The `title` field controls the sidebar section label. Page names are the MDX filenames without the extension.

### llms.txt ordering

`/llms.txt` and `/llms-full.txt` derive their page order from the Fumadocs page tree via `sortByPageTree` (`web/next/src/lib/sort-by-meta.ts`). That means the sidebar, the docs landing page, and llms.txt output all follow the same order — update the `meta.json` files and everything stays in sync.

## Search

Full-text search indexes all documentation and blog content via an API endpoint at `web/next/src/app/api/search/route.ts`:

```ts
import { createSearchAPI } from "fumadocs-core/search/server"
import { source } from "@/lib/source"

export const { GET } = createSearchAPI("advanced", {
  indexes: source.getPages().map((page) => ({
    title: page.data.title,
    description: page.data.description,
    url: page.url,
    id: page.url,
    structuredData: page.data.structuredData,
  })),
})
```

The Next.js config rewrites `/api/search` to the internal app URL to avoid CORS issues:

```ts
{ source: "/api/search", destination: `${env.NEXT_PUBLIC_APP_URL}/api/search` }
```

### Keyboard Shortcut

Press `Cmd+K` (Mac) or `Ctrl+K` (Windows/Linux) to open the search dialog from any docs page. The search dialog supports full-text search across all content, heading-level results, and keyboard navigation.
